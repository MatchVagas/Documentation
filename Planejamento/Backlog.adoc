== Critérios de Priorização

[Explique como as prioridades são definidas – por exemplo, com base no valor de negócio, urgência, dependências técnicas, risco, feedback de stakeholders, etc.]

- **Valor de negócio:** funcionalidades que trazem mais retorno para o cliente/usuário.
- **Urgência:** prazos legais, contratuais ou oportunidades de mercado.
- **Dependências:** itens que desbloqueiam outras entregas.
- **Risco técnico:** funcionalidades que exigem validação de viabilidade.

== Glossário

Definições de termos importantes para o entendimento do backlog.

* **Story Points:** Unidade de medida relativa para estimar o esforço de implementação de uma história.
* **Épico:** Uma grande funcionalidade que pode ser desmembrada em várias histórias menores.
* **Critérios de Aceitação:** Condições que uma história deve satisfazer para ser considerada pronta.

== Visão Geral do Produto

O MatchVagas é uma plataforma web que centraliza oportunidades de trabalho e estágio, facilitando o contato entre candidatos e empresas. O sistema permite que candidatos construam perfis, busquem vagas compatíveis e acompanhem candidaturas, enquanto empresas podem publicar e gerenciar suas vagas de forma eficiente. O objetivo é aumentar o índice de oportunidades no mercado de trabalho brasileiro, com foco em usabilidade, segurança e conformidade com a LGPD.

== Critérios de Priorização

- **Valor de negócio:** funcionalidades que resolvem dores reais dos usuários (candidatos e empresas) e são essenciais para o funcionamento do sistema.
- **Urgência:** requisitos legais (LGPD) e de segurança têm prioridade máxima.
- **Dependências:** itens que são pré-requisitos para outros (ex.: cadastro antes de candidatura).
- **Risco técnico:** funcionalidades complexas (busca avançada) podem exigir provas de conceito antecipadas.

== Glossário

- **Story Points:** Unidade relativa de esforço para implementar uma história (valores: 1, 2, 3, 5, 8, 13...).
- **Épico:** Conjunto de histórias relacionadas a uma grande funcionalidade.
- **Critérios de Aceitação:** Condições que a história deve satisfazer para ser considerada concluída.
- **RF:** Requisito Funcional (conforme Documento de Requisitos).
- **RNF:** Requisito Não Funcional.
